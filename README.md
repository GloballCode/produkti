## Produkti
A product stock manager SaaS for small business

## 📚 Theme
This is a stock manager, my first SaaS, built to help my aunt with product managing

## ✨ Functionalities
Register all your products, have'em all in your hand!
Keep track of your stock quantity, never stay without your products!
Register your sales, and see how much you earned per sale!
Get warned when a product is almost running out!

## 🛠 Technologies
HTML
CSS
JavaScript 
Firebase Auth - for authentication
Firestore - for database and backend

## 🎯 Objective
Help my aunt and many other small businesess to manage products easily, restock in time, and keep things in check!
